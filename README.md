# PRODIGYINFOTECH_CS_task-04
⚠️ Ethical Disclaimer: This software is for educational purposes only. Keylogging can violate privacy laws and security policies. Ensure you have explicit permission from the owner of the device and system before running this software. 
Basic keylogger using python and its libraries.


How it works:
Library: Uses pynput to monitor keyboard events.
Logging: Captures keystrokes and appends them to a file named key_log.txt.
Readability: Handles standard characters normally, whilst special keys (like Space, Enter, Tab) are formatted to ensure the log is readable.
Termination: The program runs in the background until you press the ESC key.
